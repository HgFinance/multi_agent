# Archived quantization experiments

The canonical comparison records are intentionally kept outside this archive:

- `results/aws_l4_fp8kv_v1/aws_l4_fp8kv_v1_7axis_comparison.md` — historical controlled record
- `results/aws_l4_fp8kv_v1/final_7axis_20260824/aws_l4_fp8kv_v1_final_7axis_comparison.md` — current execution record

The active runner, scorers, frozen datasets, and glossary remain in their original locations. Other benchmark runners, intermediate result files, raw JSON, provenance, and comparison outputs were moved here to reduce noise without deleting evidence.

This archive is not used by the active benchmark path and can be restored if an older experiment must be audited.
