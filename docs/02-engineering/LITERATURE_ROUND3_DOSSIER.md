## 1. 한 장 요약

| # | 발견 | 함의 |
|---|---|---|

**교차 발견**: 완전성 비평이 지목한 공백 2개(데이터 무결성·적대적 정보)는 둘 다 **"입력의 신뢰"** 문제다 — 1·2차가 "계산의 신뢰"(통계·검증·안전장치)를 다뤘다면, 3차의 최상위 교훈은 계산이 아무리 옳아도 **들어오는 데이터(과거 가격·유니버스·공시·뉴스)가 오염되면 전부 무효**라는 것. 지문 구속(1차 1위)의 데이터 버전 동결과 3절의 데이터 인증은 같은 원칙의 두 얼굴이다.

## 2. 한국 팩터 실증

기준 논문: **Han, Lee & Kang (2020), "Market anomalies in the Korean stock market"** (*JDQS* 28(2), [Emerald 공개](https://www.emerald.com/jdqs/article/28/2/3/206237)) — 148개 앤어멀리, KOSPI+KOSDAQ 2000–2019 전수 재현. 카테고리별 재현률(|t|>1.96, EW): **가치 69.2% · 모멘텀 66.7% · 거래마찰 48.2% · 투자 24.1% · 무형자산 23.5% · 수익성 5.0%**. t>2.78 생존은 27.7%뿐. KOSPI 대형주 제한 시 모멘텀 66.7%→**20%**로 붕괴 — EW+마이크로캡 인플레이션이 한국의 지배적 가짜 양성 모드.

### 장기 제약(long-only)의 구조적 함의

Stambaugh-Yu-Yuan (JFE 2012, JF 2015): 앤어멀리 수익은 **숏 다리에 불균형 집중**되고, 롱 다리 알파는 "저평가 + 차익거래 제약 높은" 종목에서만 생존. 한국은 만성 개인 주도 과대평가 + 반복되는 공매도 금지로 이 비대칭이 증폭 — **long-only 전략의 알파 원천은 "좋은 것을 사기"보다 "나쁜 것(과대평가·고MAX·고IVOL·신주발행·고자산성장)을 피하기"에 있다.** 회피 스크린의 가치는 공매도 금지 레짐에서 더 커진다(KCMI: 금지가 과대평가를 해소하지 못함을 실측).

### 즉시 실행 항목

1. **jkpfactors.com에서 한국 국가별 테마 수익률 무료 다운로드**(JKP 2023 공개 데이터, ~2025-12) → 9개 템플릿의 테마 회귀로 Gate 0 prior 직접 캘리브레이션.
2. **EW·마이크로캡 아티팩트 방어를 게이트에 내장**: 모든 재현을 EW-전체 / VW-KOSPI 브레이크포인트 2열로 보고(Hou-Xue-Zhang 표준), VW 열에서 소멸하는 가설은 격리.
3. LOWMAX·IVOL·SEO·고자산성장을 **전 템플릿 공통 회피 스크린**으로 승격, 금지 레짐에서 강화.

## 3. 데이터 무결성

**완전성 비평이 지목한 공백 ①** — "모든 3차 알파 추정은 무편향 과거 데이터를 암묵 전제하는데, 파이프라인 스스로 `SURVIVORSHIP_BIAS_DECLARED`를 미해결 WARN으로 선언하고 상폐 수익률 처리가 전무하다."

### 편향의 실측 크기

| 편향 | 실측 | 출처 |
|---|---|---|
| 상폐 수익률 누락 (NYSE/AMEX) | 실적 사유 상폐 imputation **−30%**, 소형주 프리미엄 ~1.5%p/yr 축소 | Shumway 1997 (JF) |
| 상폐 수익률 누락 (나스닥 = KOSDAQ 유사체) | 편향 **4.7배**, imputation **−55%**, 보정 후 "나스닥 사이즈 효과는 존재한 적 없음" | Shumway-Warther 1999 (JF) |
| **한국 비자발적 상폐 실측** | 매칭 부실기업 대비 초과수익 **KOSPI −90% / KOSDAQ −81%** (2003–2012) | Park-Lee-Park 2014 (PBFJ) |
| 신호별 부호 상이 | 상폐 수익률 포함 시 이익·CF·BM 전략 수익은 **증가**, 발생액 전략은 **감소** — 스칼라 헤어컷 불가 | Beaver-McNichols-Price 2007 (JAE) |
| 역투영 유니버스 | 인도 스몰캡 250 지수 9년: 바스켓 회전 82.5%, 생존자 백테스트가 연수익 **+4.94pp**(26.17% vs 21.23%)·Sharpe +0.097 과대 | Ranse 2026 (arXiv/SSRN) |
| 벤더 데이터 재작성 | 같은 DB 7회 다운로드 간 레코드 **1.6–21.7% 상이**(비무작위) | Ljungqvist et al. 2009 (JF, I/B/E/S) |
| 재작성 재무제표 룩어헤드 | as-collected DB와 비교 시 회계 소트 수익 유의 상이 — 가설 검정 뒤집힘 | Banz-Breen 1986 (JF) |

### 처방 — 데이터 인증 파이프라인 (Gate 0 상류)

1. **상폐 수익률 배선**: KRX 상폐 사유 코드 수집(CRSP 200s/500s 구분의 한국판) → 비자발적 상폐는 정리매매(7일, 가격제한 없음) 종가 실측치 우선, 부재 시 **KOSDAQ −80% / KOSPI −90% imputation**; 합병·우회상장은 교환비율/현금 조건 사용.
2. **유니버스를 구간 멤버십 테이블로 재구축**: KRX 지수 구성종목 변경 공시를 날짜순 리플레이 → `(종목, 진입일, 이탈일)` 인터벌 테이블(표준 방법론). 완성 전까지 모든 추정치에 **"+3~5pp/yr 의심 인플레이션 밴드"를 정량 스탬프**(막연한 WARN 대체).
3. **Ince-Porter 스크린을 `pit_dataset` 결정론 검증기로**: 보통주 한정 필터 / 정지 종목의 패딩 봉 결측 처리(volume==0 + 정지 플래그 조인) / **300%/50% 반전 규칙**(R_t 또는 R_{t−1} > 300%이고 복합수익 < 50%면 둘 다 결측 — 단위 오류·수정주가 역보정 오류 포착).
4. **상한가 잠금 플래그**: 종가 == ±30%(2015-06 이전 ±15%) 한도인 날은 체결 불가능 종가 — 당일 진입 체결 금지, 전략별 잠금일 노출 보고.
5. **DART 재무는 접수일(rcept_dt) 키 + 최초 제출본 불변 스냅샷**: 정정공시는 제자리 갱신이 아니라 자체 접수일의 새 행. 재수집 시 해시 diff로 벤더 재작성 검출. DART는 태생적으로 PIT(모든 공시에 접수 타임스탬프)이므로 학계의 3–4개월 랙 관례보다 **엄격히 우월한** as-of 조인이 가능 — 이 이점을 쓰는 것.
6. **SUE/PEAD·발생액은 상폐 수익률 포함으로 재추정**(부호별 이동 예상 — Beaver), Gate 0 prior를 신호별로 재캘리브레이션.
7. **Arnott-Harvey-Markowitz 데이터·표본 체크리스트를 기계화**: 출처 증명·PIT 조인·사후 제외 금지·사전 등록된 winsorization을 항목별 PASS/FAIL 인증 잡으로 — 데이터셋의 Gate 0 입장 자격을 게이트.

## 5. 적대적 정보 위험

**완전성 비평이 지목한 공백 ②** — 4절이 여는 뉴스·공시 레인은 텍스트를 OrderIntent로 바꾸는데, 1·2차는 도구 평면(MCP)과 훈련 오염만 다뤘지 **추론 시점의 조작된 입력**은 다루지 않았다. 한국은 정보 기반 조작의 문서화된 핫스팟이다.

### 위협의 실측

- **KRX 시장감시위 2024**: 불공정거래 혐의 통보 98건 — 미공개정보 60.2%, 부정거래(리딩방·SNS 포함) 18.4%, 시세조종 16.3%. **KOSDAQ이 73.5%** vs KOSPI 24.5%. 부정거래 혐의자의 88.9%가 내부자.
- **FSC 리딩방 적발(2024)**: 카카오톡·텔레그램 핀플루언서가 **700개+ 종목**에서 자기 추천 선행매매 — 변동성 큰 테마주 표적.
- **AP 해킹 크래시(2013)**: 가짜 트윗 1개("백악관 폭발")로 S&P 500 **~$134–136B**가 3분 내 증발 — 원인은 소스 필터·교차 확인 없는 단어 카운팅 알고리즘. 손실 프로파일 = 급락 후 수분 내 복원.
- **Avon/Fitbit 가짜 EDGAR 공시(2015/16)**: 진짜 공식 채널에 올라온 가짜 내용 — Avon +20%, 4배 거래량. **"DART에 있다" ≠ 인증**.
- **PoisonedRAG (USENIX Security 2025)**: 수백만 문서 코퍼스에 표적 질문당 **악성 문서 5개만 심으면 공격 성공률 ~90%** — 기존 방어(패러프레이즈·perplexity 필터) 불충분.

### 방어 설계 (개발 원칙 9 — 실패는 진입 차단 방향 — 의 구현)

1. **다중 소스 확인 게이트**: 단일 소스 텍스트로 OrderIntent 생성 금지 — *클레임*(주제가 아니라) 수준에서 독립 발행처 ≥2 또는 공식 DART 공시 확인. 일봉 레인은 지연 비용이 사실상 0.
2. **소스 신뢰 티어 + 전과 prior**: DART 발행사 공시 > 통신사·주요 언론 > 포털 > 커뮤니티/SNS. SNS발 종목 추천은 컨텍스트 전용, 절대 트리거 아님. **불성실공시법인 이력 기업은 영속적 공시 불신 할인**.
3. **결정론 펌프 시그니처 필터** (Renault 2018·Kamps-Kleinberg 2018·Xu-Livshits 2019): ① 언급량이 추세 기준 N-시그마 초과 + 동시 가격 급등 → 차단, ② "독립" 소스 간 준중복 템플릿 텍스트(봇 프로모션 시그니처) → 차단, ③ **촉매 텍스트 등장 전에 이미 가격·거래량이 달린 종목** → 뉴스가 연출됐을 가능성, 진입 거부.
4. **KRX 지정의 이중 용도**: 투자주의/경고/위험 + VI/정지 상태 = **익일 하드 차단**(1일 랙, 실시간 유효 — 단 노이즈 주의: 지정 105건 중 7건이 다음날 +30~51%). 불성실공시·시감위 통보 = **백테스트 라벨 전용**(수 주 랙, 이벤트 창은 지정 전 런업으로 백데이트).
5. **RobustRAG 격리-후-집계**: 가설 생성 LLM을 소스별 격리 실행 → 독립 소스 다수결을 통과한 클레임만 통과 — 오염 문서 ≤k개로는 출력을 못 뒤집는 **인증된 강건성**.
6. **지시/데이터 분리** (Greshake 2023): 수집 텍스트는 프롬프트에 인용 데이터로만, 명령형 스팬은 수집 시점에 제거/플래그.
7. **레드팀 스위트**: 가짜 공개매수 공시(Avon 패턴), 5-문서 포이즌 세트(PoisonedRAG 수치), 템플릿 봇 프로모션 버스트(Renault), 공개 전 타임스탬프 "유출" 기사(뉴스와이어 해킹 패턴) — **각각 진입 거부로 끝나야 통과**.

## 6. KRX 집행 설계·TCA

### 시장 구조 실측 (KRX 공식 가이드 + 학술 검증)

- 세션: 시가 단일가 08:30–09:00 → 접속매매 09:00–15:20 → **종가 단일가 15:20–15:30** (2026-06부터 프리·애프터 세션 확대 예정). 가격제한 ±30%(2015-06~). **VI**: 동적(단일 호가 ~±2–3%) / 정적(누적 ±10%) → ~2분 단일가 + 랜덤엔드(≤30초) — 주문이 2–5분 미체결로 잠길 수 있음. 틱: ₩1(<2천)~₩1,000(≥50만), 2023-01 개정 — 보드별 확인 후 하드코딩.
- 종가 단일가 비중: 공식 통계 없음(미국 ~10% 대비 낮을 것으로 추정 — KRX 감시 기준이 "단일가 물량 ≥5% + 종가 ±5% 이동"을 이상 징후로 취급). **자사 356GB 틱 이력에서 종목별로 직접 측정**하는 것이 트리아지 문턱의 근거.

### 집행 정책 청사진

1. **기본 경로 = 종가 단일가.** 신호가 종가 기반 → 벤치마크 = 공식 종가(백테스트 체결가와 정렬, 추적 오차 0). de-minimis 밴드(<5bp 또는 1틱 가치 미만) 미만 거래는 스킵.
2. **종목별 유동성 트리아지** (자사 틱 데이터 기반): 계획 수량 ≤ 종가 단일가 중위 물량의 ~5% → 단일가에 지정가 1건(직전가 ±2–3틱, 미체결 감수) / 5–20% → 절반 단일가 + 절반 14:30–15:20 수동 우선 슬라이스(POV ≤5–8%) / >20%(KOSDAQ 꼬리) → 2–3일 분산 또는 ≤5% 참여 VWAP, 기회비용 수용.
3. **주문 배치 규칙** (Cont-Kukanov 논리): 터치에 수동 게시 → (잔여 시간 < 문턱) 또는 (중간가 1틱+ 역행) 시 스프레드 관통. 넓은 틱 KOSDAQ에서 수동 게시 가치가 불균형하게 큼.
4. **미체결 잔량**: 기회비용으로 기록 후 익일 목표에 합산 — 일일 주기가 완결 백스톱.
5. **LS OpenAPI 제약**: TR별 TPS(`ThroughputQuotaRule`, 위반 시 429) — 주문 TR은 CSPAT00601/701/801. 300종목 전환 ≈ 600 메시지 → 순수 제출만 1–2분+. **15:17까지 제출 시작**, 페이로드 사전 스테이징, TR별 토큰 버킷, 429 재시도, 주문별 멱등 상태기계(VI 정지 인지).
6. **분기 재캘리브레이션** + **익일 시가 반전 모니터**(러셀 리컨 실측: 편입 +9bp→익일 −13bp 반전) — 자사 매수가 체계적으로 반전되면 한계 종목을 단일가에서 장중으로 이동(혼잡 자가 진단).

### 임팩트 캘리브레이션과 TCA

- **√법칙은 보편**(Zarinelli 8백만 메타주문 δ≈0.52–0.54 · 도쿄거래소 전수 확인 Sato-Kanazawa 2024) → KRX에서도 성립 전제. 소액 구간은 선형(Bucci) — 초기 비용은 스프레드 지배 예상.
- 사전: 자사 호가·틱으로 **종목별 Amihud + 장중 Kyle λ 테이블**(5분 중간가 수익률 ~ 부호 거래량 회귀; Hasbrouck 2009가 Amihud를 λ 프록시로 검증) → 참여율 캡의 근거.
- 사후: 실체결 축적 후 `cost_bps = a·spread + Y·σ_daily·√(Q/ADV)` 2-파라미터 적합 — 300종목이면 **1주 체결로 Y가 구속**됨.
- **`tca_results` 스키마 (지금, 페이퍼 단계에 구현)**: 부모 주문당 — 결정 시각/가격(신호 종가), 최초 라우팅 시 도착 중간가, 목표/체결 수량, 체결 VWAP, 공식 종가, 창 구간 시장 VWAP, 수수료·세금, T+10분·T+1시가 반전 마크. 자식 체결당 — 시각·가격·수량·수동/공격 플래그·대기시간·상태 전이(VI 포함). **주 KPI = 공식 종가 대비 슬리피지.** 이것으로 Perold/Kissell 분해 전항 계산 가능.

## 7. 자본 배분·사이징

### 수학적 골격

- **Kelly 분수의 드로다운 역산** (Thorp 2006 + Busseti-Ryu-Boyd 2016): 분수 c에서 P(자본이 x배로 하락) = x^(2/c−1). 실측: **풀 Kelly는 절반 손실 확률 50%, 하프 12.5%, 쿼터 <0.8%** — 성장률은 g(c)=c(2−c)·g_full이라 하프가 성장 75% 보존. 제약 "P(최저점 < α) < β"는 λ = ln β/ln α로만 결정되고, 브리지 공식 **c = 2/(λ+1)**. 예: "30% 드로다운 확률 ≤10%" → λ=6.46 → **c ≈ 0.27 (쿼터 Kelly)**. 파라미터 오차 하 과베팅 위험(Samuelson·MTZ) 때문에 실무 c ∈ [0.2, 0.5].
- **변동성 타기팅 = 분수 Kelly** (c = 목표변동성/SR): 기존 채택된 vol targeting에 **σ\* = c × SR_net** (SR_net = Harvey-Liu 헤어컷 적용 샤프)로 c를 배선. 예: SR_net 0.8, c 0.25 → σ\* = 20%.
- **Grossman-Zhou 플로어를 서킷브레이커로**: 위험 비중 ≤ k·(NAV − 0.7·최고 NAV)/NAV — 변동성 추정과 독립적으로 선언된 최대 드로다운 접근 시 강제 디리스킹.

### 티어·램프·블렌드·현금

| 티어 | 페이퍼 0% → 소액 라이브 풀 총 ~10% NAV, 전략당 0.5–2% **+ RTS 6 Art.8식 다차원 캡**(종목 수·주문 수·명목) → 전액은 램프 경유만 | RTS 6 controlled deployment |
| 램프 | w(t) = w_target × g(T_live): **~1개월+페이퍼 대비 추적오차 정상 → 25% / ~3개월 → 50% / ~6개월 → 100%**; 괴리 시 단계 리셋. 근거: 다중검정 헤어컷과 Kan-Zhou T-의존 수축이 라이브 일수 축적으로 완화 — "증거 비례 사이징"의 공식화 | Harvey-Liu · Kan-Zhou 2007 |
| 승격 후 기대 | **엣지 감쇠가 기본 시나리오** — 인큐베이션 펀드는 승격 전 +3.5%/yr 우위가 승격 후 소멸(선택 편향). 2차 e-process 게이트도 같은 편향을 가짐 | Evans 2010 (JF) |
| 블렌드 가중 | **역변동성 × 할인 스킬**: w_i ∝ SR_net,i/σ_i — long-only 슬리브의 균일 고상관 하에서 ERC가 역변동성으로 축약(공분산 역산 불요). 무거래 밴드로 재조정 | Maillard-Roncalli-Teiletche 2010 · Anderson et al. 2012 비용 경고 |
| 현금 버퍼 | cash ≥ max(**2% NAV**, 99% 2일 순유출 + 미지급 수수료·세금); 미결제 매수 ≤ 결제 현금 + T+2 매도 대금 — 유입 실패가 강제 매도를 못 만들게. 주식형 관행 2–5%(채권형이 끌어올린 전체 평균 7–8%보다 낮게) | Chernenko-Sunderam · KRX T+2 (T+1은 2026 하반기 표준 초안 단계) |
| 기대수익 입력 | 점추정 금지 — 사후분포 평균 + 파라미터 불확실성 분산 인플레이션(Barberis 2000), 표본 길이 T로 수축(Kan-Zhou 3-펀드) — 60일 라이브 슬리브는 램프 게이트 이전에 수학적으로도 작아짐 | Barberis 2000 · Kan-Zhou 2007 |

## 8. 인용 충실 합성

### 문헌이 정한 현실

- 최고 모델도 답변 문장의 **50%에서 완전한 인용 지지 실패**(ALCE, EMNLP 2023). 자동 인용 판정자 자체가 **~80% F1 천장**(AttributionBench) — 검증기 점수는 여유 마진 있는 게이트로, 절대 ground truth로 취급 금지.
- 클레임 단위 자동 검증은 이미 실용 수준: FActScore 추정기는 인간 대비 **오차 <2%**(인간 평가 $26K를 대체), SAFE는 크라우드 인간과 72% 일치·불일치 시 76% 승·**20배+ 저렴** — 모든 응답에 돌릴 수 있는 비용.
- **금융 QA의 수치는 생성 금지가 결론**: FinanceBench — GPT-4-Turbo + 검색이 **81% 오답·거부**; DocFinQA — 전체 공시 문서로 가면 오류율 2배(병목은 추론이 아니라 선택); FinQA 계열 — 3단계+ 산술에서 정확도 ~22.8%로 붕괴.
- RAGAS류 충실성 지표는 게임 가능(발췌만 하고 답 안 하는 응답이 만점, 빈 컨텍스트가 만점 아티팩트) — **단독 게이트 금지**, ARES식 보정(인간 라벨 ~150개 + PPI) 또는 conformal 보정으로 문턱 설정.

### S0–S5 응답 파이프라인 (QA 레인 구현 사양)

```
S0 검색 게이트   — 컨텍스트 정밀도/재현율 + 충분성 분류기(Joren, ICLR 2025).
                  불충분 → 합성 금지, 기권/명료화 (프런티어 모델은 불충분 컨텍스트에서 자신 있게 오답).
S1 결정론 계산   — 모든 수치·집계·PIT 사실은 도구/DB + 계산 로그.
                  FAIL: 로그된 계산·인용 스팬으로 추적 안 되는 숫자.
S2 인용 합성     — 생성 시점 스팬 구속 인용(실제 청크 오프셋 — Anthropic Citations 패턴: 가짜 참조가 구조적으로 불가능).
                  FAIL: 존재하지 않는 문서/청크 ID (구조 검사, 무관용).
S3 클레임 분해+함의 — FActScore식 원자 클레임 분해 → 인용 구절 NLI 함의.
                  게이트: 인용 재현율 ≥0.85 · 정밀도 ≥0.75 · 무인용 클레임 ≤0.1 (이후 conformal 재보정).
                  FAIL: 실질 클레임(수치·권고·리스크)의 미함의. ← 기존 Evidence-QA 엔진의 정확한 자리
S4 수리 루프     — S3 판정을 외부 피드백으로 RARR식 1회 수정 (FinLFQA: 외부 피드백 없는 refinement는 무효) → 재검증 → 실패 클레임 제거 or 기권.
S5 방출 결정     — {S0 충분성, S3 점수, 신뢰도} 위의 선택적 예측 보정기. 미달 → 사유 명시 기권.
하드 FAIL 목록: 가짜 인용 ID / 미함의 수치 / PIT 위반 / 빈 컨텍스트 충실성 만점(게이밍) / 사실 질의의 무인용 답변.
```

운영 규율: 검증기-인간 불일치를 주간 샘플 감사(판정자 80% F1 천장), 검증기-인간 일치율 자체를 KPI로. **1차 지도 3위(QA fail-closed)의 "결정론 검사 층"이 바로 S1–S3이고, 잠자는 Evidence-QA 엔진의 배선 자리가 S3다.**

## 9. 통합 실행 순서

2차 플레이북의 실행 순서에 3차 발견을 병합한 갱신판. **가장 큰 변화: 데이터 무결성(신규 0번)이 지문 구속과 동급 최우선으로 올라온다** — 컷오프-이후 백필 증거(2차 방책 A)조차 상폐 편향 데이터 위에서는 부풀려지기 때문.

| 순서 | 작업 | 출처 | 노력 | 이유 |
|---:|---|---|---|---|
| **0** | **데이터 인증 v0**: 상폐 수익률 imputation + 구간 멤버십 테이블 + Ince-Porter 스크린 + 상한가 잠금 플래그 (§3) | 3차 | 중 | 모든 알파 추정의 상류. 완성 전까지 "+3~5pp/yr 의심 밴드" 정량 스탬프 |
| 1 | 워커 Stage 0 (2단계 출력·검증기·합의 격상) | 2차 C | 하 | 훈련 불요, 즉시 |
| 2 | 지문 구속 + 컷오프·LAP 스탬프 + 익명화 | 1차·2차 A | 하 | 늦을수록 백필 증거 오염 |
| 3 | **Gate 0 prior 재조정** (§2 표) + jkpfactors.com 한국 데이터 회귀 + EW/VW 2열 표준 + LOWMAX 유니버스 스크린화 | 3차 | 하–중 | 공장이 지금 캐는 방향을 즉시 교정 |
| 4 | **BUILD NOW 템플릿 3개**: PEAD(시계열 SUE) → 펀더멘털 합성 → 자사주(목적 필터) + SEO 즉시 제외 규칙 (§4) | 3차 | 중 | 아이디어 고갈의 구조 해소 — 문헌 검증 고 prior 공급. **단 0번 이후 백테스트**(Beaver: 상폐 처리로 부호별 이동) |
| 5 | e-process 라이브러리 + 컷오프 백필 검정 | 2차 A | 중 | 0·2번 위에서 |
| 6 | 블렌딩 v0 + **자본 프로토콜 배선**: c=2/(λ+1) → σ\*, GZ 플로어, 티어·램프 (§7) | 2차 B + 3차 | 중 | 사이징 수학 완결 |
| 7 | 생애주기 모니터 v0 + 트립 표 | 2차 D | 중 | 킬스위치(1차 2위)와 동시 |
| 8 | **TCA 로깅 스키마 + 종목별 Amihud/λ 테이블 + 종가 단일가 물량 측정** (§6) — 페이퍼 단계에 구현 | 3차 | 중 | 실주문 전 완비, 페이퍼 현실성(2차 A-3)에도 공급 |
| 9 | **S0–S5 응답 파이프라인** — Evidence-QA를 S3로 배선, 충분성 게이트, conformal 보정 (§8) | 1차 3위 + 3차 | 중–상 | 사용자 질의 단계의 품질 골격 |
| 10 | **적대적 정보 게이트** (§5): 다중 소스 확인 + 펌프 필터 + KRX 지정 소비 + 레드팀 스위트 — **뉴스 레인(4번의 5·6위) 가동 전 필수** | 3차 | 중 | 텍스트→주문 경로의 선행 조건 |
| 11 | e-LOND 게이트 + 공장 수준 e-process | 2차 A | 하 | 5 위에 규칙 하나 |
| 12 | LoRA Stage 1–2 · 레짐 계기판 · 집행 라우터(LS TR 토큰 버킷) · 블렌드 업그레이드 | 2차 C·D + 3차 | 상 | 후순위 |

**의존 관계 요지**: 0번(데이터)과 2번(지문)이 모든 통계 장치의 전제 → 3·4번이 공장의 "무엇을 캘까"를 교정 → 5·6·7번이 "믿을 수 있는 판정·사이징" → 8·10번이 실주문·뉴스 레인의 관문 → 9번이 사용자 서비스 품질.
