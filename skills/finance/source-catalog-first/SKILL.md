# 카탈로그 우선 탐색 — "없다"는 검색 결과여야 한다, 가정이 아니라

## 왜 이 스킬이 필요한가 (실측 2026-08-13)

KRX 정보데이터시스템이 유료화되어 PER/PBR 을 결제로 사려던 참이었다.
카탈로그를 한 번 검색하자 **이미 가진 LS OpenAPI 안에** `t3320 FNG_요약`
(FnGuide 밸류에이션 전체)이 무료로 있었다 — 7월 29일부터 문서 43장 안에
계속 있었는데, 365개 TR 중 큐레이션된 몇 개만 쓰느라 아무도 안 열어봤다.

같은 날 실측이 하나 더 있다: 에이전트가 "투자자별 수급 도구는 카탈로그에서
확인되지 않는다"고 답했는데, 실제로는 연결 문제였다. **"없다"는 답은 어느
카탈로그를 어떻게 검색했는지와 함께여야 검증 가능하다.**

## 언제 쓰나 — 이런 말을 하기 직전

- "그 데이터는 없다" · "그런 도구는 없다"
- "유료라서 못 한다" · "구독/결제가 필요하다"
- "구현이 안 돼 있다" · "수집을 새로 만들어야 한다"

**말하기 전에 돌린다.** 위 문장은 결론이 아니라 검색 쿼리다.

## 우리가 이미 가진 카탈로그 4층

| 층 | 검색 도구 | 규모 | 커버 |
|---|---|---|---|
| LS 증권 TR | `ls_tr_catalog(질의어)` → `ls_tr_spec(코드)` | **365 TR** | 시세·수급·공매도·프로그램·밸류에이션(FnGuide)·업종·파생 |
| 한국 거시 | `ecos_search(질의어)` → `ecos_items` → `ecos_series` | 통계표 수천 | 금리·물가·환율·통화·국제수지 |
| 글로벌 | OpenBB `discovery` 도구 → 카테고리 활성화 | **도구 200+** | 옵션체인·ETF·채권·글로벌 매크로 |
| 기업 공시 | `dart_search_disclosures` / `sec_filings` | 전 상장사 | 국내·미국 공시 원문 좌표 |

폴백: 네 층에 다 없으면 `tavily_search`(전체 웹) → `read_url`(본문).

## 절차

1. **질문을 데이터 축으로 번역한다.** "수급" → 투자자별 매매, "밸류" →
   PER/PBR, "금리" → 기준금리 계열. 축이 곧 검색어다.
2. **해당 층을 검색한다.** 한 단어로 시작해 넓게 — `ls_tr_catalog("공매도")`
   처럼. 결과 0이면 유의어로 한 번 더 (수급/투자자/매매동향).
3. **명세를 확인한다.** `ls_tr_spec(tr_code)` 로 요청·응답 필드의 한글
   설명까지 읽는다. 응답에 원하는 필드가 실제로 있는지가 판정 기준이다.
4. **세 갈래로 정확히 보고한다:**
   - `executable_tool` 있음 → 그 도구로 실행
   - 카탈로그에 있으나 미큐레이션 → **"없다"가 아니라 "t____ 에 있으나
     실행 도구 미구현"** 이라고 보고하고 큐레이션 요청을 남긴다.
     그 목록이 곧 개발 백로그다.
   - 네 층 + 폴백에도 없음 → 그때만 "없다". **어느 카탈로그를 어떤
     검색어로 뒤졌는지 같이 적는다** — 없다는 주장도 재현 가능해야 한다.

## 함정 (전부 실측)

- **문서와 실제 응답이 다를 수 있다.** t1717 은 문서상 OutBlock1(배열)인데
  실제는 OutBlock 이 배열이고, t1602 는 `svolume_XX` 가 실제로는 `sv_XX` 다.
  `ls_tr_spec` 의 주의문을 읽고, 첫 호출의 실제 키를 확인하라.
- **모의(PAPER) 서버는 rsp 00000 에 빈 행을 준다** — "진짜처럼 생긴 가짜".
  조회면은 LIVE 다(도구가 이미 그렇게 설정돼 있다).
- **확정결산 vs 예상을 구분하라.** t3320 의 PER 53.65(확정)와 예상PER
  26.85 는 다른 질문에 대한 답이다.
- **일일 예산이 있다.** 소진되면 도구가 거부한다 — 지어내지 말고
  `external_budget`/`ls_budget` 으로 상태를 확인해 보고하라.
